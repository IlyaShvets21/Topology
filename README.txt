Sequence Pair Interface (Парная последовательность)

О программе:
	Данное программное обеспечение представляет собой инструмент для автоматизированного размещения блоков в рабочем поле на основе алгоритма парной последовательности (Sequence Pair).

	Программа написана на языке C++ с использованием фреймворка Qt5. Она предоставляет графический интерфейс пользователя (GUI) для загрузки исходных данных, запуска алгоритма размещения, визуализации результатов и анализа метрик качества.

Основные возможности:
	Загрузка входных файлов с описанием блоков и парной последовательности.

	Выполнение алгоритма размещения блоков с возможностью их поворота для оптимизации площади.

	Графическое отображение размещенных блоков на рабочем поле.

	Визуализация соединений (нетов) между блоками.

	Вывод подробной информации о процессе работы в окно лога.

	Автоматическое создание выходного файла с результатами размещения.

Интерфейс программы: 

	Рабочее окно программы состоит из следующих элементов:

	Рабочее поле — основное пространство для графического отображения взаимного расположения блоков.

	Окно лога — область, где отображается вся информация о состоянии программы и этапах выполнения алгоритма.

Состояние программы (Status) — индикатор текущего этапа:

	Ready — программа готова к работе (необходимо выбрать входной файл).

	File Selected — входной файл выбран, можно запускать алгоритм.

	Done — алгоритм завершен, результаты готовы.

Информация о выбранном файле — отображает имя текущего загруженного файла.

	Run — кнопка запуска основного алгоритма размещения (неактивна до загрузки файла).

	Clear — очистка окна лога.

	Browse — кнопка выбора входного файла на устройстве.

	View — кнопка отрисовки размещенных блоков (неактивна до завершения алгоритма).

	Show nets — переключатель отображения соединений между блоками.

Руководство пользователя:

	Шаг 1. Выбор входного файла
	Нажмите кнопку Browse и выберите на устройстве файл, соответствующий требованиям формата (пример формата см. в файле «Пример теста»). После успешной загрузки в окне лога появится соответствующее уведомление, а статус изменится на File Selected.

	Шаг 2. Запуск алгоритма размещения
	Нажмите кнопку Run. Программа выполнит алгоритм размещения. По завершении в окне лога отобразятся метрики (площадь, HPWL, время выполнения), а также автоматически будет создан выходной файл (например, output.txt).

	Шаг 3. Получение результатов
	Ознакомьтесь с выходным файлом, который содержит:

		Координаты левых нижних вершин блоков.

		Размеры блоков.

		Информацию о том, был ли блок повернут в ходе размещения.

		Плотность упаковки.

		Суммарную метрику HPWL (Half-Perimeter Wirelength).

		Время выполнения размещения.

	Шаг 4. Отрисовка результатов
	Нажмите кнопку View, чтобы графически отобразить блоки на рабочем поле.

Примечание: Зеленый цвет блока указывает на то, что в ходе размещения он был повернут для минимизации определенного параметра.

Формат выходных данных:
	Выходной файл (дублируется в логе) содержит:

		Placement: список блоков с координатами (X, Y) и размерами Width x Height.

		Quality metrics:

		total area — общая площадь.

		total HPWL — суммарная длина соединений.

		decoding time — время работы алгоритма.

Системные требования:
	ОС: Windows / Linux / macOS

	Компилятор: Поддерживающий стандарт C++11 и выше

	Библиотеки: Qt5 (модули Core, Gui, Widgets)
